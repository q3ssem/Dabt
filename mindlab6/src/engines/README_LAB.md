# اختبار المحركات الفعلي (معمل تقني فقط)

- `src/engines/playcanvas-driver.ts`: مشهد مجسمات بدائية مؤقتة باستخدام PlayCanvas 2.24.2، سحب 360°، لوحة مفاتيح، تحرير موارد، تحميل كسول.
- `src/engines/pixi-driver.ts`: مشهد مؤقت لقياس تحميل PixiJS 8.23.0 وعمر التطبيق، ويستخدم WebGL.
- الصفحة التجريبية `lab.html` تُبنى عبر `npm run build:lab` إلى `dist-lab/`، خارج ملفات نشر `dist/` المخصص للتطبيق الأساسي.
- **ليست ألغازًا نهائية** ولا تحقق جودة التصميم أو الأداء الواقعي؛ ولا تُحمل عند دخول التطبيق الرئيسي.
- أدلة إتاحة 3D على الهاتف الفعلي، وفقد WebGPU والسياق، والجودة، واللمس متعدد الأصابع ضمن `research/experiments/EXP-0002-statue360-engines/`.
- لا تُستورد الأبحاث إلى التطبيق، وتظل محركات الرسم مسؤولة عن العرض فقط؛ لا تعرف أسرار فتح الأبواب ولا مفاتيح الحفظ.

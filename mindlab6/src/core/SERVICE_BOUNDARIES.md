# حدود الخدمات المشتركة ودورة الحياة — MindLab 6.0

**الوضع:** عقود معماريّة قابلة للاختبار؛ خدمات حفظ اللاعب والترقيات لم تُوصل إلى أي لعبة. فرع 6.0 تجريبي فقط.

## ما يعمل بالفعل
- `GameRegistry`: أسماء/أنواع عرض وتحميل كسول دون تشغيل المحرك في الصفحة الرئيسية.
- `GameHost`: `open / pause / resume / close / destroy`، إلغاء استدعاءات التشغيل القديمة، فصل DOM، تحرير الجلسة، الاستجابة لإخفاء التبويب.
- `ResourceScope`: يتيح لكل driver تسجيل تنظيف `defer()` أو مستمعات `listen()`؛ الإغلاق يعكس ترتيب التسجيل ويكمل رغم فشل تنظيف منفرد.
- خدمات `save / audio / progression / router` **تُمرّر بالحقن** على `context.services`؛ وجود المنافذ لا يعني أن تنفيذها أو توافقها مع 5.5.30 قد اكتمل.
- `context.resources` نطاق مستقل لكل مرة تبدأ فيها اللعبة، يُحرَّر عند الإغلاق، الاستبدال، فشل التحميل/التشغيل أو فشل `mount` بعد إنشاء موارد.

## المسؤوليات المقترحة والخط الفاصل

| المنفذ | يمتلك | لا يجوز أن يمتلك |
|---|---|---|
| `save` | نسخة schema ونقل اختياري موثق بعد EXP-0001، الحفظ الذري وتعارض النسخ | تغيير `miran:v2` أو أي مفتاح آخر قبل اختبار توافق واسترجاع |
| `audio` | فتح الصوت بإيماءة، الكتم، وقف الأصوات عند الخلفية، سياسة الأصوات المتزامنة | محرك الرسم أو قواعد حل الألغاز |
| `progression` | شروط الإتاحة والفوز/الأختام بمصدر قواعد مثبت | تفسير "شاهد المحطة" كـ"فتحها" أو كشف الأسرار مبكرًا |
| `router` | عناوين/تاريخ تنقّل RTL ومراقبة الشاشة النشطة | إعادة أطلس الملاحة المحذوف أو العبث بهوية الألغاز |
| `GameHost` | سلامة الجلسة وعمر الموارد وأخطاء التشغيل | قراءة/كتابة حفظ المستخدم مباشرة |
| `renderer driver` | لوحة اللعب وGPU واللمس والموارد | تغيير نتائج الحفظ أو شروط التلميحات |

## اختبارات واجبة قبل النقل
1. اختبار `ResourceScope` (ترتيب LIFO، أحداث WebGL، تكرار التخلص، تحرير الموارد مع الفشل).
2. اختبار إبدال لعبة 2D/3D بعشرة/عشرين تكرارًا دون تسريب معالج حدث أو سياق GPU على هاتف فعلي.
3. بعد جرد V5: مقارنة قراءة/كتابة البيانات القديمة وتوافق فتح 21/19/21/24 محطة و86 لغزًا؛ **لم تُنفذ**.
4. بعد مجسم GLB فعلي: lost/restored GPU context على Safari، ووقف/استعادة المؤقتات والصوت والـRAF، وقياس FPS قبل اختيار PlayCanvas أو Babylon.

هذا المستند **لا** يمنح رخصة لتغيير الحفظ أو إدخال ملفات V5 إلى `src/`.

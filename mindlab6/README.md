> هذا مجلد مشروع مستقل داخل فرع Git خاص بالمراجعة، **وليس مستودع Git منفصلًا**. لم يُعدّل تطبيق 5.5.30 ولم يُدمج شيء إلى main.

## قبل أي عمل أو دردشة جديدة
اقرأ `START_HERE.md` ثم `PROJECT_STATE.json` ثم `handoff/CURRENT_TASK.md`. 
**مصدر الحقيقة هو ملفات الفرع، وليس ملخص محادثة قديمًا.**

## الأقسام
- `src/`: نواة الإصدار الجديد. ممنوع نسخ محرك أو ملف قديم إليها دون تدقيق تبعياته واختبارات مكافأته.
- `research/`: **مختبر التجارب والأبحاث**. ترقيم EXP-0001، EXP-0002... للأبحاث والفرضيات والنماذج والكود التجريبي. هذا المسار لا يُحمّل إلى التطبيق المنتج.
- `research/REGISTRY.json`: فهرس حي برقم كل تجربة وحالتها ومكان أدلتها.
- `research/decisions/`: قرارات معمارية مرقمة ADR.
- `handoff/`: آخر خطوة منجزة والخطوة التالية والمشكلات والاختبارات وسجل الجلسات.
- `tests/`: اختبارات البنية النظيفة والقواعد الأساسية، ودورة حياة اللعب المستقلة عن المحرك.
- `src/core/game-host.js` و`game-registry.js`: أساس فتح وإغلاق الألعاب ديناميكيًا دون تحميل محركات ثقيلة مقدمًا.
- `research/decisions/ADR-0004-web-game-engines.md`: اختيار المحركات المبدئي ومحاذير الأداء.
- `research/experiments/EXP-0002-statue360-engines/`: بروتوكول اختبار التماثيل 360°؛ **لم ينفذ بعد**.
- `tools/`: التحقق من الفهارس والتوثيق.

## بناء الويب والمحركات المعزولة

حزم النموذج: **Vite 8.3.8 + TypeScript 7.0.2**، و**PlayCanvas 2.24.2** لمشهد ثلاثي الأبعاد مؤقت، و**PixiJS 8.23.0** لمشهد 2D مؤقت. الحزم معرفة بإصدارات محددة في `package.json`، مع CI لتنزيلها وتجميعها.

- `npm run build` ينتج `dist/` للتطبيق الخفيف دون مكتبات المحركات.
- `npm run build:lab` ينتج `dist-lab/` للمعمل المنفصل `lab.html`.
- `npm run verify` يختبر النواة، وTypeScript، وبناء المسارين، ومنع تسريب 3D والأبحاث في التطبيق الأساسي.
- النماذج الإجرائية ليست ألغازًا معتمدة. لا GLB فني ولا نتائج FPS/بطارية أو اختبار iPhone فعلي حتى الآن.

## تشغيل النواة
```bash
cd mindlab6
npm install
npm run verify
npm run dev
# افتح http://localhost:5173/
# للمعمل فقط: npm run dev:lab ثم افتح http://localhost:5173/lab.html
```

شاشة النواة الحالية **معاينة للهيكل فقط**؛ أرقام المحتوى أهداف نقل من المصدر، وليست ألعابًا قابلة للعب حاليًا.

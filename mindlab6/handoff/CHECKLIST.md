# قواعد تسليم كل جلسة

- [ ] قرأت START_HERE وPROJECT_STATE وCURRENT_TASK وREGISTRY من أحدث Commit.
- [ ] عرّفت رقم المهمة/التجربة قبل البدء.
- [ ] لم أنسخ كودًا أو أصولًا خارج قائمة الأصول المثبتة.
- [ ] شغلت `npm test`، وما يخص اللعبة من اختبارات إضافية.
- [ ] فصلت النتائج المثبتة عن الفرضيات أو أرقام مستهدفة.
- [ ] حدّثت سجل التجربة + الفهرس + CURRENT_TASK + PROJECT_STATE + SESSION_LOG.
- [ ] سجلت SHA النهائي وأي فشل/قيد.
- [ ] لم أعدّل V5 أو main أو أدمج فروعًا.

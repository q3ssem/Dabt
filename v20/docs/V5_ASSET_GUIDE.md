# Art asset guide v5

## Explorer sprite atlas
`assets/characters/explorer-spritesheet.png` is 1024×160; eight 128×160 frames. Order: idle, walk cycle, alternate idle, airborne. The matching SVG is editable vector source.

## Environment plates
`assets/backgrounds/` contains six original layered SVG plates. They are reference assets for scene composition and parallax implementation; the current Canvas painter still draws its procedural scene and does not yet composite every plate as a full multi-layer parallax scene.

## Style
Warm paper, imperfect ink outlines, gouache-like fills, restrained grain, readable silhouettes, distinct palette per biome. No Monster Boy game assets or character designs are reused.

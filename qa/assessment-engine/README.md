# ضبط دماغك PRO — Assessment Engine v1.3

## الملفات
- `Dabt_Assessment_Engine_v1.3.js`: محرك القياس والتقييم.
- `test_assessment_engine_v1_3.js`: اختبارات Node.js.
- التطبيق الرئيسي الحالي موجود في جذر المستودع باسم `index.html`، وقسم التلفزيون في `tv/`.

## الوظائف
- قاموس لثمانية مجالات معرفية.
- فصل جلسات التدريب عن القياس.
- التحقق من المدخلات والأزمنة وعتبة النجاح.
- حساب الدقة والإحصاءات الوصفية لزمن الاستجابة.
- دعم البرامج متعددة المراحل، والتجميع الموزون بعدد المحاولات.
- ملخصات حسب المجال والنمط وبيانات لوحة اللاعب.
- تخزين محلي، منع التكرار، تصدير واستيراد JSON، والتحقق من السجلات.

## تشغيل الاختبارات
من هذا المجلد:
```bash
node test_assessment_engine_v1_3.js
```

## عقد الربط المختصر
تستخدم اللعبة `window.DabtAssessmentEngine`، وتنشئ جلسة عبر `scoreSession` ثم تحفظها عبر `createStore().add(session)`. يجب أن ترسل كل مرحلة الإجابات الخام في `responses`. المحرك لا يحدد صحة قاعدة اللعبة ولا يتحكم في إظهار الإجابة أثناء اللعب.

## ملاحظة QA
هذه نسخة اختبار داخل فرع تجريبي. لم يتم دمجها في `main` ولم يتم استبدال التطبيق المنشور.

- **جزيرة الكنز — حكايات البحار السبعة (5.0):** حكاية ثم لغز ثم مكافأة. سبعة بحار، ٢١ محطة بـ٢١ نوع لغز، ولكل محطة ثلاثة تحديات (الحل، أقل حركات، بدون تلميح). أدوات تُكتسب وتُستعمل فعلًا في المحطات التالية، وسبعة أسرار تصير أدلة باب النهاية. طاقم الرحلة: رِواء، نُهى، نَبض، شِبل، سُهيل، ورد، نوفل. التصميم في `docs/SEA1_DESIGN_5_0_AR.md` و`docs/SEA2_3_DESIGN_5_0_AR.md` و`docs/SEAS4_7_DESIGN_5_0_AR.md`.
- **طفل:** ملفات للأطفال بأعمار ٤–٥، ٦–٧، ٨–١٠، ١١–١٢ مع وقت يومي محدد وقسم لولي الأمر.
- **التلفزيون:** نسخة منفصلة في [`tv/`](tv/) تُلعب على الشاشة الكبيرة والجوال ريموت، وفيها «كاهوت الجلسة».

## التشغيل محليًا

```
python3 start.py
```

ثم افتح http://localhost:8080. لا يحتاج بناء أو تثبيت حزم. الخطوط والرسوم مرفقة. أضيف Service Worker بإصدار 4.2.3: بعد نجاح تثبيته تُحفظ الواجهة والخطوط، وتُحفظ صور الألعاب عند طلبها؛ لا يُضمن رسم الألعاب غير المفتوحة دون اتصال. يحتاج HTTPS أو localhost. الحدود الدقيقة في docs/CHANGELOG_4_2_AR.md وdocs/CHANGELOG_4_2_1_AR.md.

## 5.4.6 — عهد الطريق الثامن
- توسيع مشهد النهاية بملخص بصري للأختام السبعة، مع عرض نص كل دليل كما ورد في مخطوطته.
- إضافة كلمة ختامية للجد تربط حماية الطريق برسالة الرحلة: إبقاء الممر آمنًا ومفتوحًا للمسافرين.
- إبراز أفراد الطاقم السبعة في لحظة الخاتمة، مع الإبقاء على أسمائهم وأدوارهم وأصولهم الأصلية.
- إضافة إمكانية إعادة مشاهدة خاتمة الجد من الخريطة، وحفظ خلاصة العهد في دفتر الرحلة بعد إكمال باب الطريق الثامن.
- لا تغيير في منطق الألغاز أو معرّفات المحطات أو الأسرار أو مفتاح الحفظ.

## 5.4.5 — عبور قصصي بين البحار
- إضافة ستة مشاهد انتقالية تربط البحار السبعة وتُظهر أثر الختم السابق في الفصل اللاحق.
- المشاهد تستخدم رسومات الطاقم الأصلية ومشاهد المحطات الموجودة، دون إدخال أصول بديلة أو تغيير قواعد الألغاز.
- الانتقال اختياري ويمكن تجاوزه، كما يبقى فتح المحطات من الخريطة كما هو.

## 5.4.4 — أطلس البحار ودفتر الطاقم

أضيفت بطاقات مصوّرة للبحار السبعة تعرض المملكة والجزيرة والختم وتقدم المحطات الثلاث، كما تظهر ملاحظة فرد الطاقم المرافق بعد حل كل محطة برسومته الأصلية. لا تتغير قواعد الألغاز أو معرّفات المحطات أو مفتاح الحفظ.

## الاختبارات

```
npm test                 # منطق الرحلة والحفظ وطبقات الرسم (Node فقط)
npm run test:browser     # تشغيل فعلي في Chrome: smoke (كل الألعاب والألغاز)، journey (الرحلة كاملة بالنقر، الحفظ، الصوت، الإطارات)،
                         # challenges (كل التحديات ولغز اليوم)، sweep (التبويبات، الإعدادات، الطفل، دون اتصال)
```

اختبار المتصفح يحتاج `pip install playwright` ومتصفح Chrome، والخادم المحلي شغّال. لمحرك Safari: `python3 -m playwright install webkit` ثم أضف `--engine webkit` لأي اختبار في qa/browser.
يتضمن الاختبار `qa/browser/cognitive_addons.py` فحصًا مخصصًا لتشغيل «أذن يقظة» و«حارس الإشارة» على شاشة جوال، بما في ذلك تشغيل النغمات وإعادة الاستماع وفتح المرحلة بعد الاجتياز.

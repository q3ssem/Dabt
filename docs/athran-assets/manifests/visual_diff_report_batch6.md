# تقرير الاختلافات البصرية والفحص — الدفعة السادسة (MindLab 5.5.28)

## 1. المحطات الأربع المنتجة (الدفعة السادسة والأخيرة من المحطات الـ21)
1. **`pz_asong` — أغاني الأعماق** (`region_08_creatures` / `reg:7` بحر المخلوقات المهاجرة)
2. **`pz_aflow` — مفترقات التيار** (`region_08_creatures` / `reg:7` بحر المخلوقات المهاجرة)
3. **`pz_arelic` — أرشيف الآثار الأولى** (`region_09_heart` / `reg:8` قلب أَثْرَان)
4. **`pz_aheart` — قلب أَثْرَان** (`region_09_heart` / `reg:8` قلب أَثْرَان)

## 2. الاختلافات البصرية والترقيات
- **إقليم بحر المخلوقات المهاجرة (`reg:7`):** مياه عميقة متدرجة من الفيروزي النهاري إلى الكحلي الليلي، وحيتان وقناديل حيوية مضيئة وممرات تفرّع بحرية.
- **إقليم قلب أَثْرَان (`reg:8`):** أرشيف حجري ذهبي تحت الأرض للمصادر الخمسة، وهضبة قلب أَثْرَان المطلّة على الساحل المتحرك مع طاولة الخريطة الحجرية والمرصد الفلكي.
- **اكتمال المحطات الـ21:** بإتمام الدفعة السادسة أصبحت جميع المحطات الـ21 (`ASTN[0..20]`) تمتلك 5 مشاهد مستقلة وعناصر تفاعل مربوطة بالكود الفعلي، مع بقاء الحاجة لإضافة ملفات `puzzle_vfx` لمحطات الدفعات 1–3 وبعض الدفعة 4 عند مرحلة الاستكمال النهائي.

## 3. المتبقي في الحملة بعد الدفعة السادسة
- الآثار الـ14 (`ATR[0..13]`)، العوالم السرية الـ5 (`pz_w*`)، لوحات الخاتمة الـ5، واجهات الفصل الـ14، ومؤثرات الـVFX التكميلية لبعض المحطات الأولى.

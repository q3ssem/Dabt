# بوابة جودة الكتابة والألغاز — يجب اجتيازها لكل لغز

اجعل القرار **قبول / تعديل / رفض** مع دليل. لا تصف النص بأنه عبقري دون اختبار.

| البعد | معيار القبول |
| --- | --- |
| وفاء الأصل | القاعدة ومعرف اللغز ومراحل الحفظ لا تتغير دون سبب واختبار |
| عربية سليمة | خلوها من الغموض النحوي والالتباس في الضمائر والرموز والأرقام |
| عدالة اللغز | جميع المعلومات اللازمة متاحة، ولا توجد قفزة في المنطق |
| فرادة الحل | حل وحيد مثبت، أو تعداد صريح للحلول المكافئة التي يقبلها المحرك |
| صعوبة مدروسة | إضافة استنتاجات أو قيود مترابطة حقيقية؛ ليست إطالة النص أو إخفاء معلومة ضرورية |
| تصميم التلميحات | يُعطي اتجاهًا ثم علاقة ثم خطوة، ولا يكشف الجواب مباشرة |
| تدرج مناسب | صعوبة متسقة مع المرحلة السابقة واللاحقة والعمر المستهدف |
| تنوع معرفي | لا يكرر الفكرة نفسها بمفردات جديدة فحسب |
| تماسك القصة | لا يسبق الأحداث أو يفشي الأسرار ولا يخلط الرحلة الجانبية بالحملة |
| إتاحة بصرية | وصف موجز، جدول منظم للأرقام/الرموز، لا ازدحام أو تشتيت |
| توافق البرنامج | حل ومفاتيح الحفظ والأقفال والاختبارات مستمرة بعد التعديل |
| الأثر التوثيقي | مسار المصدر وSHA، النسختان قبل وبعد، سبب التغيير وحالته |

## طريقة تقويم نوعي مختصر
امنح كل لغز درجة 0–5 على: الوضوح، أصالة الاستنتاج، عدالة الحل، تدرج التلميحات، اندماج القصة. اذكر سبب الدرجة، ولا تجمعها في رقم واحد يوهم بوجود بحث تجريبي على لاعبين. اختبره بمراجعة مستقلة وبمحرك اللعبة عند تغيير المنطق.

## سياسة ضبط الصعوبة
- المستوى السهل لا يعني الابتذال؛ يكفي استنتاج أساسي واضح.
- المتوسط يحتاج دمج قرينتين أو أكثر، دون قفزة خفية.
- المتقدم يحتاج عدة مراحل استنتاج وتحقق/استبعاد وتخطيطًا، مع جواب منطقي معلوم.
- التوقيت لا يصنع صعوبة معرفية وحده؛ استعمله فقط عندما تكون المهارة الأساسية هي السرعة أو الانتباه الزمني.
- لا تُضف عقوبات أو ألغازًا جانبية أو مؤثرات صوتية تناقض مبدأ اللعب الأصلي.

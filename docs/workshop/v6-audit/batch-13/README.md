# إعادة التدقيق ١٣ · حزمة تسليم iPhone وiPad

الفهرس [delivery-index.json](delivery-index.json) يصنّف المعرّفات الـ٨٦ ويشير إلى دفعة كل بطاقة. وتربط [خريطة الظهور](../appearances.json) المحطات الـ٨٥ بمصادر قواعدها. تشترك ٤٠ محطة بمعرّف مكتبة وتبقى ٤٥ مستقلة. المعرّفات والمحطات المحجوبة مسجّلة كذلك. تبقى قواعد الحفظ والفتح وترتيب القصة وفق مرجع 5.5.30.

## وصلات العروش

قاعة الملوك السبعة لها معرّف واحد. تظهر لكل عرش قاعدة مستقلة ويبدأ تلميحه من الصفر. هذه النصوص تكمل بطاقة الدفعة ٨.

| العرش | قاعدة المشهد | توجيه الانتباه ← العلاقة ← الخطوة التالية |
| --- | --- | --- |
| الأقفال | اضبط الأقراص لتصدق النقوش معًا. | قيد على قرص ← اربط القرص بمعادلة ← عوّض قيمته في قيد آخر |
| التماثيل | اختر الباب الذي تبقى معه أقوال الصادقين والكاذبين متسقة. | افترض بابًا ← اختبر قولًا يربطه بالصدق ← تتبّع إحالة إلى تمثال آخر |
| الساعات | اختر عددًا موجبًا يجعل العقارب عند ١٢ معًا. | ابدأ بعقرب ← احسب دورة رجوعه ← افحص مرشحيه على العقرب الثاني |
| التنانين | خذ حراشف من كومة واحدة حسب الحد. من يأخذ الأخيرة يفوز. | انظر إلى حجم الكومة ← احسب الباقي بعد مجموعات كاملة ← جرّب ترك البواقي في وضع متوازن |
| الشيفرات | امنح كل رمز حرفًا مختلفًا، ثم اختر الوجهة بعد فك السجل. | قارن الرمز المكرر ← راجع الكلمة المكتملة جزئيًا ← قارِنها بأسماء المراسي |
| الأنماط | أكمل تسلسل كل تنين وحدد مخالفة الشرخ عند ظهورها. | ابحث عن تكرار ← قارن القفزات ← اختبر موضع الشرخ قبل اختيار التالي |
| البحار | ضع الأدوات حول العرش وفق الجوار والتقابل والاتجاه. | ابدأ بالفتحة العليا ← ثبت الأداة المقابلة ← راجع العلاقة عند التفاف آخر فتحة إلى الأولى |

## بوابة الجهاز

لكل ظهور مستقل راجع «ابدأ» ثم اللعب فورًا، وصحة القاعدة دون معرفة الحل. أعد المسار على iPhone صغير وآخر حديث وعلى iPad بالوضعين، في الثيمين وRTL، مع نص مكبّر. في الحركة جرّب السحب والإلغاء وخروج التطبيق واستئنافه والتدوير منتصف الفعل. في الأدلة ثبّت قرينتين وقارن الفرضيات داخل اللوحة. في الحساب اقرأ الرقم واتجاهه دون اعتماد على اللون. قبل الإقفال اختبر حفظًا قديمًا، محاولة فاشلة، فوزًا وعودة للبطاقة، وفتح المحطة التالية في ترتيبها. طبّق الاقتراحات التي تغيّر المحرك على فرع مستقل واعرضها للمراجعة.

حالة التسليم **اكتمال التغطية التحريرية والفحص المنطقي بعينات**. لوحتا المقاس في الدفعة ١٢ مخططات بصرية. إعادة رسم الأصول المطلوبة، دمج التفاعل، واختبارات iPhone وiPad الفعلية شروط باقية. عدد الألغاز المعتمدة للنقل في السجل صفر.

# تسليم الألغاز لمختبر العقل 6.0

تغطي إعادة التدقيق الآن ٤٠ من ٨٦ معرّفًا. تدقيق أسئلة القصة الـ٣٢ محسوب داخل معرّفها.

يربط [فهرس الظهور](appearances.json) محطات القصة الـ٨٥ بمصادر قواعدها. تشترك ٤٠ محطة في معرّف مع لغز المكتبة. وتبقى ٤٥ محطة على محركاتها المستقلة. التشابه بين آليتين يُسجّل كمقارنة، مثل أنابيب المد والأنابيب، ويحتفظ كل منهما بمعرّفه ومستوياته.

للتجربة افتح batch-01/pipe/index.html من نسخة محلية للمستودع. تشغّل الصفحة ملفاتها النسبية وأصول نهى والنافورة والصمام من الرسم الموجود. النموذج مستقل عن واجهة الإصدار وحفظه. المسارات الجديدة والرسوم المطلوبة للتصدير مذكورة في بطاقة اللغز.

يتطلب اعتماد النقل اكتمال النص واللوحات والتلميحات وأصولها، ثم إعادة الحل من واجهة اللعب وفحص اللمس والقراءة في RTL والثيمين. تُراجع تغييرات المحرك أو بيانات الإنتاج على فرع هندسي منفصل. يستمر ترتيب الدفعات بحسب سجل الورشة.

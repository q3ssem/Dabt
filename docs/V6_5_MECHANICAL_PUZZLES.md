# ضبط دماغك PRO — v6.5

## نطاق التحديث
أضيفت آليتان تفاعليتان داخل Phaser 4 بدلاً من سؤال اختيار من متعدد في مواجهتين موجودتين:

1. **مرآة الحارس — مختبر انعكاس الضوء:** تدوير مرآة بزيادات 45 درجة، ثم اختبار مسار الشعاع. النجاح يفتح الختم ويحفظ التقدم.
2. **تروس الحارس — آلية التعشيق:** تحريك ترس وملاحظة دوران الترس المتشابك في الاتجاه المعاكس، ثم فحص المحاذاة. النجاح يفتح الختم ويحفظ التقدم.

تُعرض تغذية راجعة عند فشل المحاولة، ويمكن إغلاق الآلية عبر زر الإغلاق أو Escape. بقية الألغاز ونظام حفظ v6.0 لم يتغيرا.

## حدود التنفيذ
- الرسوم الميكانيكية مرسومة برمجياً داخل Phaser وليست أصولاً مرسومة يدوياً جديدة.
- هذه آليتان تجريبيتان ضمن الحملة، وليستا نظام ألغاز فيزيائياً عاماً.
- فحص المصدر واختبارات البنية لا يثبتان جودة اللعب الفعلية على الأجهزة.

## التحقق
- `node --check engine-phaser/src/main.js`
- `node qa/test_v65_mechanics.mjs`
- اختبارات Phaser السابقة وv6.0
- سلامة ملف ZIP

لم يُنفذ `npm install` أو `npm run build` أو اختبار متصفح/جهاز فعلي في هذه البيئة. لم يتم النشر إلى GitHub.

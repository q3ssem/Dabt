# MindLab 5.5.28 — رقعة دمج مكتبة أَثْرَان الفنية (athran-assets-1)

## خط الأساس
نسخة المشروع المستلمة `28 كلودي.zip`، وإصدار `package.json` فيها 5.5.28. ملف README الأصلي كان يحمل عنوان 5.5.27؛ تم توحيد العنوان في README إلى 5.5.28، وأضيفت رقعة cache مستقلة `athran-assets-1` حتى لا تختلط ملفات الأصول الجديدة بذاكرة التخزين المؤقت السابقة، مع توثيق التباين هنا.

## الدمج
- أُضيفت الأصول الـ546 المعتمدة من `FinalX.zip` تحت `atheran/assets/` مع الحفاظ على `relative_path` لكل أصل.
- أضيف `asset_inventory_master.json` وسجل تشغيل مركزي `assets-runtime.js` يوفر دوال الوصول للأصول بالـ`asset_id` وتجميعها حسب المحطة والمنطقة واللغز.
- رُبطت صور الخريطة ذات الطبقات، وصور البطلات والشخصيات الثانوية في حوارات الحملة، وعلامات المحطات الـ21 على الخريطة بحسب حالة الفتح/الإكمال، ولافتات المحطات ومعاينات المراحل الثلاث، وبيئة المدخل المستقلة وطبقات بيئات المناطق وخرائطها، وصور الآثار الـ14، وأغلفة ومشاهد العوالم السرية الخمسة، ولوحات الخاتمة الخمس.
- أضيفت خلفية المرحلة المناسبة عند تشغيل محطة من محطات أَثْرَان أو أحد العوالم السرية.
- سجلت قطع الألغاز والحالات الـ80 في الفهرس مع واجهات `puzzleState` و`puzzleStates` لاختيار حالة كل قطعة، بحيث تصل إليها محركات الألغاز حسب المحطة عبر `MINDLAB_ATHRAN_ASSETS.puzzle(stationId)`، مع الإبقاء على SVG والتفاعلات القديمة كما هي حيث لم تكن هناك نقاط ربط موثقة وآمنة لكل عنصر. لذلك فهذا دمج كامل للملفات والفهرسة والربط العام، وليس ادعاءً بأن كل عنصر PNG استبدل بالفعل داخل كل عنصر تفاعلي.
- أضيف runtime وCSS وManifest إلى قائمة ملفات التثبيت؛ صور المكتبة تُخزّن في cache عند أول طلب عبر Service Worker لتجنب تنزيل المكتبة الكبيرة بالكامل دفعة واحدة.

## ما لم يتغير
- لا تغيير في `ASTN` أو `ASW` أو `ATR` أو معرفات الألغاز.
- لا تغيير في مفاتيح الحفظ `miran:v2` و`mindlab:expedition10:v1` أو بنية التقدم.
- لا تغيير في قواعد الألغاز أو مولداتها أو حلولها.
- بقيت `expedition10/` منفصلة عن أَثْرَان ولم تُخلط أصولها.

## التحقق
- اكتمال ملفات Manifest: 546/546، دون معرفات أو مسارات مكررة.
- تحقق SHA-256 لكل أصل بعد نسخه إلى المشروع مقابل السجل الرئيسي.
- اجتاز ZIP النهائي فحص CRC: 1,215 مدخلاً، منها 546 ملف أصل، دون تلف في الأرشيف.
- فحص بنية JSON/JS وصياغة الملفات المصدرية.
- اختبارات Node المنطقية والتكاملية: تُسجل نتائجها في `qa/reports/5.5.28/`.
- لم يُنفذ اختبار على جهاز iOS/Android حقيقي في هذه البيئة؛ يلزم فحص الهاتف النهائي قبل إعلان الاعتماد التشغيلي.

# معيار الصقل البصري — لوحات ألعاب مختبر العقل 5.5.29

## النطاق
طبقة `ds/board-polish.css` المشتركة؛ لا تغيّر محركات اللعب أو الألغاز أو قواعد النقاط أو مفاتيح الحفظ. تُحمَّل مع تبويب الألغاز أو بدء لعبة مباشرة، لا عند ظهور الرئيسية.

## نظام اللون
- الوضع الفاتح (الأساسي): رقّ عاجي دافئ، نص داكن، وألوان أدوات واضحة دون صناديق إضافية.
- الوضع الداكن (الثانوي): خلفية كحلية وحبر عاجي، مع ألوان أدوات ملائمة للتباين.
- أزرق: رجوع وإغلاق. ذهبي: تلميح. تركواز: معلومات. بنفسجي: دفتر. أخضر: صوت أو إعادة. أحمر: استسلام.
- ألوان عناصر الألغاز الميكانيكية والحالات الصحيحة/الخاطئة تبقى للعبة نفسها، ولا تُستبدل عبر محدد CSS عام.

## الخطوط والرموز
- Tajawal: النص الأساسي، تعليمات الألغاز، الأزرار والعناوين العملية.
- Aref Ruqaa: عناوين القصة فقط.
- أيقونات أدوات اللعب دائرية، هدف لمس 44px، ورموزها الأصلية محفوظة.
- رسومات الشخصيات والعناصر اليدوية تُعرض بنسبة أبعادها الأصلية `object-fit:contain` في أشرطة الأدوات؛ لا تُنشأ شخصيات SVG.
- ورقة القواعد تعرض النصوص دون تكديس مستطيلات متداخلة.
- مُختار المراحل يعرض مرحلة اللعب الحالية بلون تركوازي، والمقفلة بمظهر واضح.

## بوابة القبول
- `npm test` يتضمن اختبارًا للثيمات والأيقونات وتحميل CSS دون اتصال.
- فحص Chrome وWebKit لأحجام 320 و390 بكسل، في الوضعين الأبيض والداكن، والتحقق من استدارة أدوات اللعب وتباينها.
- صور مرئية في Artifacts للاطلاع قبل الدمج.
- تبقى اختبارات المراحل الـ140، الألغاز، الـ27 حالة واجهة، ترحيل الحفظ والعمل دون اتصال كما هي.

هذا تحديث عرضي للمراجعة؛ أي خلل في اللوحات يجب إصلاحه قبل دمج الفرع الرئيسي.

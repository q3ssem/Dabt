# Dabt PRO — خطة V10 إلى V15 بالتوازي

## قرار التنفيذ
المسارات الستة تعمل بالتوازي على قاعدة مصدر واحدة. لا تنشأ ستة تطبيقات أو ستة فروع إصدار متعارضة. تُدمج المكونات عبر عقود بيانات واختبارات مستقلة، ويصدر إصدار تجميعي واحد بعد اجتياز بوابات الجودة.

## المسارات

| المسار | نطاق V10–V15 | بوابة القبول |
|---|---|---|
| المغامرات | عناصر الماء/النار/الضوء/الطاقة، ألغاز محلية وعابرة للمناطق، AI حالات، زعماء، نهايات متفرعة | تفاعل قابل للعب مع حفظ الحالة واختبار المسار كاملاً |
| الفن والتحريك | دليل أسلوب موحد، spritesheets، حالات idle/walk/jump/hit/attack، مؤثرات بيئية | اتساق بصري، أحجام أصول موثقة، أداء مقبول على الهاتف |
| مختبر العقل | تدقيق المهام، إزالة التكرار، مولدات متوازنة، مراجعة علمية | صحة مفاتيح الإجابة، فصل التدريب والقياس، حدود تفسير مكتوبة |
| عالم الطفل | أربعة نطاقات عمرية، تفاعلات لمس، سرد قصير، صوت اختياري، خصوصية | مراجعة تربوية، عدم فرض مؤقت على الأصغر، عدم جمع بيانات حساسة |
| المنصة المشتركة | حالة تقدم موحدة، ترحيل حفظ، تصدير/استيراد متحقق، RTL ووصولية | اختبار الترحيل والنسخ الاحتياطي ولوحة المفاتيح وتقليل الحركة |
| الجودة والإطلاق | اختبارات وحدات وتكامل، بناء إنتاجي، اختبارات متصفح وأجهزة | صفر أخطاء حرجة، تقرير QA صريح، موافقة المستخدم قبل النشر |

## ترتيب الدمج المتوازي
1. تأسيس عقود الحالة والبيانات المشتركة.
2. تنفيذ كل مسار في وحدات مستقلة مع اختبارات.
3. دمج أسبوعي محلي بعد اختبارات المسارات.
4. اختبار تكاملي للنقاط المشتركة: الحفظ، اللغة، التنقل، الوصولية.
5. تجميد الميزات وإصلاح العيوب قبل الإصدار المرشح.

## حدود لا يجوز تجاوزها
- لا تُسجل محاولات معرفية وهمية ولا تُحوّل نتائج لعبة إلى IQ.
- لا تُوصف الأنشطة بأنها تشخيصية أو معيارية دون تحقق مستقل.
- لا يُعرض ذكاء عدو أو زعيم على أنه مكتمل قبل اختبار سلوكه أثناء اللعب.
- لا تُوصف SVG ثابتة بأنها تحريك مرسوم إطاراً بإطار.
- لا يُعلن نجاح بناء Vite أو اختبار جهاز قبل تشغيله فعلياً.
- تبقى التطويرات محلية؛ لا GitHub ولا نشر دون موافقة صريحة.

## الحالة الحالية لهذه الدفعة
تم تأسيس نواة حالة موحدة، قواعد تفاعل العناصر، عقد الألغاز العابرة للمناطق، عقد مراحل الزعيم، معايير مراجعة ألعاب العقل، نطاقات الطفل العمرية، وأساس وصولية. هذه طبقة بنية وتعاقدات واختبارات؛ ليست ادعاءً بأن كل محتوى V10–V15 النهائي اكتمل.

## Latest implementation note — V11 boss/story pass
The final guardian now has a separate memory gate followed by a timed three-phase combat encounter. Defeating it unlocks a saved two-way ending choice. Automated source-level checks pass; browser/device validation and Vite production build remain open gates.

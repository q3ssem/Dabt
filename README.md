# ضبط دماغك

## روابط التشغيل
- [التطبيق](https://q3ssem.github.io/dabt/): مختبر العقل، جزيرة الكنز، رحلة الكواكب، عالم الطفل (V21)
- [نسخة التلفزيون](https://q3ssem.github.io/dabt/tv/)
- [الريموت من الجوال](https://q3ssem.github.io/dabt/tv/remote.html)

## المجلدات
- جذر المستودع: نسخة V21 المبنية الجاهزة للتشغيل على GitHub Pages.
- `v21/`: المصدر الكامل والاختبارات والتقرير (`v21/REPORT_V21_AR.md`).
- `tv/`: نسخة التلفزيون والريموت.

## تحديث النسخة المبنية
```bash
cd v21 && npm install && npm run build && cp -r dist/. ..
```
الإصدارات السابقة (التطبيق القديم وV20) حُذفت من الفرع الرئيسي، وما زالت محفوظة في سجل git.

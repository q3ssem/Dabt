# مختبر العقل — MindLab

تطبيق ألغاز عربي يعمل في المتصفح. يضم قسم حركة ومسارات سبعة ألغاز، ولكل لغز ٢٠ مرحلة ثابتة (١٤٠ مرحلة إجمالًا). مكتبة الألغاز والرحلات تشترك في ورقة قواعد قابلة للإغلاق وتصميم ملائم للجوال.

## التشغيل

شغّل `python3 -m http.server 8765` من جذر المستودع ثم افتح `http://localhost:8765/`.

## التحقق والتصميم

- اختبارات المشروع عبر `npm test`. يتطلب فحص ملف الألوان المولّد حزمة Python `tinycss2`.
- اختبارات المراحل عبر `npm run test:authored-stages`.

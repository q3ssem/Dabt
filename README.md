# ضبط دماغك PRO — V20.0 Offline Preview

منصة عربية RTL تضم مختبر العقل، عالم الطفل، جزيرة الكنز، ورحلة الكواكب، مع مشغل مغامرات Phaser 4 منفصل. هذه نسخة معاينة للاختبار وليست إصداراً إنتاجياً معتمداً.

## التشغيل على الكمبيوتر

1. فك ضغط الحزمة.
2. افتح الطرفية داخل مجلد `Dabt_PRO_V18_0`.
3. شغّل: `python3 -m http.server 8080`
4. افتح `http://localhost:8080`.

لا تفتح `index.html` مباشرة من مدير الملفات؛ وحدات JavaScript وخدمة التخزين المؤقت تحتاج خادماً محلياً أو HTTPS.

## التثبيت على iPhone

1. ارفع المشروع إلى استضافة HTTPS (مثلاً GitHub Pages) أو شغّله على الكمبيوتر.
2. إذا شغّلته على الكمبيوتر، اجعل iPhone والكمبيوتر على شبكة Wi-Fi نفسها وافتح `http://عنوان-الكمبيوتر:8080`.
3. في Safari اضغط مشاركة ثم «إضافة إلى الشاشة الرئيسية».
4. افتح المنصة مرة واحدة والإنترنت متاح حتى تُحمّل ملفات الواجهة وتُخزّن محلياً. بعد ذلك يمكن فتح واجهة المنصة الأساسية دون اتصال إذا كانت الملفات المطلوبة قد زارتها سابقاً.

## التخزين والنسخ الاحتياطي

- التقدم محفوظ محلياً في المتصفح والجهاز الحالي. لا تتم مزامنته تلقائياً بين الأجهزة.
- من «سجل اللاعب» استخدم «تصدير النسخة الاحتياطية» لحفظ بيانات التطبيق في ملف JSON.
- لاسترجاعها على جهاز آخر افتح المنصة هناك ثم اختر «استعادة نسخة».
- احتفظ بنسخة احتياطية خارج الجهاز؛ مسح بيانات المتصفح قد يحذف التقدم المحلي.

## تشغيل مغامرات Phaser 4

من `engine-phaser` نفّذ `npm install` ثم `npm run dev`. للبناء استخدم `npm run build`. هذا المشغل منفصل عن واجهة المنصة الرئيسية، وقد يحتاج تثبيت الاعتماديات.

## الاختبارات

من `engine-phaser` نفّذ `npm test`. تشمل الاختبارات قواعد الألعاب والمحتوى والتكامل، والنسخ الاحتياطي والاستعادة، وفحص HTTP، وروابط الإصدار، ومتطلبات PWA الأساسية.

## ما لم يُتحقق منه بعد

- لم يكتمل بناء Vite في بيئة إعداد هذه الحزمة لعدم توفر الاعتماديات.
- لم تُجرَ تجربة تفاعل حقيقية على Safari أو Chrome أو أجهزة لمس ضمن هذه البيئة.
- التخزين دون اتصال يعتمد على أن تفتح المنصة أول مرة عبر HTTP/HTTPS وأن تُحمّل الملفات المطلوبة. لا يشمل ذلك تلقائياً تنزيل اعتماديات Phaser الخارجية.
- نتائج المختبر مؤشرات أداء تدريبية وليست اختبار ذكاء معيارياً أو أداة تشخيص طبي.

# مختبر العقل — MindLab 5.5.29

تطبيق عربي لتدريب العقل والألغاز والمغامرات، يعمل عبر المتصفح ويدعم اللمس على الهاتف والتخزين للعمل دون اتصال بعد تجهيز الموارد.

يشمل مكتبة من **86 لغزًا نشطًا**، وحملة البحار السبعة والقصر وأَثْران، ورحلة جانبية تضم **24 مرحلة**. تُحمّل الأصول الكبيرة وألعاب الرحلة عند الطلب حتى لا تزدحم الواجهة أو تزيد تكلفة بدء التشغيل.

## التجربة والتشغيل

- النسخة المنشورة: https://q3ssem.github.io/Dabt/
- التشغيل المحلي من جذر المستودع: `python3 -m http.server 8765` ثم افتح `http://127.0.0.1:8765/`.
- لا تمسح بيانات المتصفح عند تجربة ترقية الإصدار: قد تحتوي على تقدم لاعب محلي.

## اختبارات الجودة

- فحوص المصدر ومرجعيات الملفات: `npm test` (بعض الاختبارات تتطلب Python وحزمة `tinycss2`).
- اختبارات المراحل: `npm run test:authored-stages`.
- فحوص Chromium وWebKit التفاعلية تعمل عبر GitHub Actions، ولا تحل محل تجربة iPhone Safari فعلي.

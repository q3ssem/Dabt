# ضبط دماغك PRO

النسخة الحالية المنشورة هي بوابة التجربة ومختبر التقييم. هذا المستودع هو مصدر العمل الحالي.

## ابدأ التجربة
- [الصفحة الرئيسية](https://q3ssem.github.io/Dabt/)
- [مختبر التقييم](https://q3ssem.github.io/Dabt/assessment/)
- [لعبة القاعدة المتغيرة](https://q3ssem.github.io/Dabt/assessment/rule-switch.html)
- [لوحة اللاعب](https://q3ssem.github.io/Dabt/assessment/dashboard.html)

## مكونات النسخة الحالية
- `assessment/rule-switch.html`: لعبة القاعدة المتغيرة، 7 مراحل و54 محاولة، بوضعَي التدريب والقياس.
- `assessment/dashboard.html`: لوحة نتائج التدريب والقياس، سجل الجلسات، الاتجاهات، واستيراد/تصدير النسخ الاحتياطية.
- `qa/assessment-engine/Dabt_Assessment_Engine_v1.3.js`: محرك التقييم الموحد.
- `assessment/index.html`: مركز تشغيل المختبر.

## الاختبارات
- محرك التقييم v1.3: اختبارات التحقق الصارم، التسجيل، البرامج متعددة المراحل، التجميع الموزون، الاتجاهات، التخزين المحلي، النسخ الاحتياطي والاستعادة، الترحيل، التكرارات وأخطاء الحصة.
- القاعدة المتغيرة v1.1: 7 مراحل و54 محاولة، صحة الأهداف، وجود الإجابات، عدم تكرار الخيارات، ربط المجالات، وتوافق سياسة التغذية الراجعة مع وضع القياس.

## حدود النسخة التجريبية
- تحفظ النتائج محلياً في المتصفح والجهاز، ولا توجد مزامنة سحابية.
- افتح اللعبة واللوحة من نفس النطاق والمتصفح لرؤية السجلات نفسها.
- النتائج مؤشرات أداء داخل الألعاب وليست اختبار ذكاء معيارياً أو تشخيصاً طبياً.
- لم يُعتمد الاختبار الفعلي على Safari/iPhone أو VoiceOver بعد، كما لم يكتمل اختبار تفاعل شامل على جهاز حقيقي.
- GitHub Pages قد يحتاج وقتاً قصيراً لنشر آخر commit؛ تحقق من رابط اللعبة بعد تحديث الصفحة.

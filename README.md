# ضبط دماغك

تطبيق عربي لتدريب الدماغ، فيه ثلاثة أنواع ملفات تختارها عند أول فتح:

- **الأساسي:** 27 لعبة مبنية على أبحاث علمية بمستويات تتكيف مع أدائك، و«مدينة الألغاز» فيها 72 لغز قصة في 9 فصول على خريطة مرسومة، و19 نوع ألغاز تتولد بلا نهاية.
- **طفل:** 10 ألعاب للأعمار 4–6 و7–12، وملف خاص لكل طفل، ووقت لعب يومي محدد، وقسم لولي الأمر.
- **التلفزيون:** ألعاب وألغاز تُلعب بالريموت (الأسهم وزر OK وزر الرجوع).

ملف واحد `index.html` بدون أي مكتبات خارجية (عدا خط Tajawal من Google Fonts، وخطّا الرسم اليدوي يُحمَّلان فقط عند اختياره). الشكل الكلاسيكي هو الأساسي، مع خيار «مرسوم باليد» (ورق دفتر أو سبّورة). كل لغز له لوحة مائية تُرسم داخل التطبيق. الأصوات تُولَّد داخل التطبيق نفسه بدون ملفات صوت. التقدم يُحفظ في متصفح الجهاز.

## حدود علمية وتقنية
النتائج مؤشرات أداء داخل الألعاب وليست اختبار ذكاء معيارياً أو تشخيصاً طبياً. التحسن في لعبة لا يثبت انتقال التحسن إلى الذكاء العام أو الحياة اليومية. لم تُجر بعد معايرة مستقلة أو تجربة سريرية أو اختبارات Safari/iPhone وVoiceOver شاملة. لوحة التقييم ومحرك التطبيق الأساسي لم يُثبت بعد أنهما يعرضان جميع نتائج كل الألعاب القديمة في سجل موحد؛ لا تفترض هذا التكامل حتى إتمام اختبار E2E.

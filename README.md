# مختبر العقل

تطبيق عربي لتدريب الدماغ (اسمه السابق «ضبط دماغك»). يعمل من المتصفح على الجوال، ويُحفظ التقدم في الجهاز نفسه.

- **الأساسي:** ألعاب العقل المبنية على أبحاث علمية (الذاكرة، المكان، المنطق، السرعة، الانتباه، المرونة) بمستويات تتكيف مع أدائك، ومكتبة الألغاز القديمة بكل ألغازها ومستوياتها.
- **جزيرة الكنز — حكايات البحار السبعة:** قصة ثم دليل ثم لغز ثم أثر الحل. سبعة فصول، ٢١ محطة، سبعة أسرار جانبية، وأدوات تُكتسب في نهاية كل فصل وتساعد في الفصل التالي.
- **طفل:** ملفات للأطفال بأعمار ٤–٥، ٦–٧، ٨–١٠، ١١–١٢ مع وقت يومي محدد وقسم لولي الأمر.
- **التلفزيون:** نسخة منفصلة في [`tv/`](tv/) تُلعب على الشاشة الكبيرة والجوال ريموت، وفيها «كاهوت الجلسة».

## التشغيل محليًا

```
python3 start.py
```

ثم افتح http://localhost:8080. لا يحتاج بناء أو تثبيت حزم. الخطوط والرسوم داخل المستودع، فيعمل التطبيق دون اتصال بعد أول فتح.

## الحفظ

مفتاح الحفظ لم يتغير (`miran:v2`)، فيبقى تقدم من استخدم «ضبط دماغك» كما هو بعد التحديث. رحلة الجزيرة في `treasureV3`. النسخة الاحتياطية من «مستواي» تشمل الألعاب وملفات الأطفال ودفتر الرحلة.

## الاختبارات

```
npm test                 # منطق الرحلة والحفظ وطبقات الرسم (Node فقط)
npm run test:browser     # تشغيل فعلي في Chrome بمقاس جوال: كل الألعاب والألغاز والمحطات الـ٢١
```

اختبار المتصفح يحتاج `pip install playwright` ومتصفح Chrome، والخادم المحلي شغّال.

## الملفات

| المسار | المحتوى |
|---|---|
| `index.html` | المحركات الأصلية للألعاب والألغاز |
| `upgrade/` | مكتبة الألعاب، ألعاب الطفل الجديدة، الحفظ والنسخ الاحتياطي |
| `legacy/` | طبقة الرسوم للألعاب والألغاز القديمة وأطالسها (`legacy/art/*.webp`) |
| `treasure/` | جزيرة الكنز: القصة والمحطات والمنطق والواجهة والرسوم |
| `fonts/` | خطّا Tajawal وAref Ruqaa (رخصة OFL) |
| `icons/`، `manifest.webmanifest` | أيقونة التطبيق وإضافته للشاشة الرئيسية |
| `qa/` | الاختبارات، ومحرك التقييم الذي يحمّله التطبيق |
| `tools/` | أدوات التطوير: تفريغ خلفيات الأطالس، تحديث بصمات المحركات |
| `docs/` | سجل التغييرات وتقارير النسخ السابقة |

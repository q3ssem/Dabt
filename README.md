# ضبط دماغك

تطبيق عربي لتدريب الدماغ، فيه ثلاثة أنواع ملفات تختارها عند أول فتح:

- **الأساسي:** 27 لعبة مبنية على أبحاث علمية بمستويات تتكيف مع أدائك، و«مدينة الألغاز» فيها 112 لغز قصة في 14 فصلًا على خريطة مرسومة، و29 نوع ألغاز تتولد بلا نهاية. أبرزها «جزيرة الكنز»: خريطة قديمة مرسومة باليد عليها رحلة من 9 محطات بالترتيب (رسالة الزجاجة، خريطة القرصان، ممر الشعاب، جسر الوادي، مشاعل الكهف، قسمة الغنيمة، أين دُفن الكنز؟، احفر بذكاء، قفل الصندوق)، وفي آخرها صندوق ينفتح عن كنز فريد يُحفظ في «خزانة الكنوز». كل لغز فيه زر «إعادة» وزر «المرحلة التالية».
- **طفل:** 14 لعبة للأعمار 4–6 و7–12 مع بومة ترافق الطفل، وملف خاص لكل طفل، ووقت لعب يومي محدد، وقسم لولي الأمر، وزر رجوع للملف الرئيسي بالضغط المطوّل.
- **التلفزيون:** ألعاب وألغاز تُلعب بالريموت (الأسهم وزر OK وزر الرجوع).

ملف واحد `index.html` بدون أي مكتبات خارجية (عدا خطّي Tajawal وAref Ruqaa من Google Fonts، وخطّا الرسم اليدوي Lemonada وReem Kufi Fun يُحمَّلان فقط عند اختياره، مع اختيار لون الخلفية). الشكل الكلاسيكي هو الأساسي، مع خيار «مرسوم باليد» (ورق دفتر أو سبّورة). كل لغز له لوحة مائية تُرسم داخل التطبيق. الأصوات تُولَّد داخل التطبيق نفسه بدون ملفات صوت. التقدم يُحفظ في متصفح الجهاز.

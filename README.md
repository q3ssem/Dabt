# مختبر العقل — MindLab 5.5.29

تطبيق عربي لتدريب مهارات العقل والألغاز والمغامرة في المتصفح، به حملة البحار السبعة وقصر المرايا وأَثْران ورحلة جانبية مستقلة. تضم مكتبة الألغاز في الفهرس الحالي **86 لغزًا فعالًا**، بينما تضم الرحلة الجانبية **24 محطة**. يعتمد الرسم اليدوي ثنائي الأبعاد، والثيم الأبيض أساسي والأسود ثانوي، مع تحميل عناصر اللعب الكبيرة عند الحاجة.

## التشغيل

من جذر المشروع:

```sh
python3 -m http.server 8765
```

ثم افتح `http://127.0.0.1:8765/`. الموقع المعلن: https://q3ssem.github.io/Dabt/ . نجاح النشر وحده لا يثبت سلامة التشغيل على الجهاز الحقيقي.

## اختبارات الجودة

- `npm test` — اختبارات المصدر، منطق الألغاز، سلامة المسارات والحفظ. تتطلب بعض الفحوص Python وحزمة `tinycss2`.
- `npm run test:authored-stages` — فحص المراحل المؤلفة.
- `node tools/audit-assets.cjs --json cleanup-audit.json` — جرد **للقراءة فقط**، يظهر الملفات المتطابقة والمراجع الثابتة واحتمال المراجع الديناميكية. التقرير لا يجيز حذف أي ملف تلقائيًا.
- اختبارات الواجهات وChromium وWebKit على GitHub Actions. النجاح في المحاكي لا يُعد اختبارًا على iPhone Safari فعلي.

## سياسة الحذف والحفظ

- لا يجوز إزالة صورة لمجرد وجودها في `legacy` أو `hold` أو `work_review`؛ فبعض المسارات تُنشأ ديناميكيًا.
- الملفات الفنية ذات البصمة المتطابقة قد تُستخدم من مسارين؛ عند توحيدها يجب تحديث كل مستهلك وقائمة الأصول دون اتصال واختبارات الواجهة.
- مفاتيح تقدم اللاعبين ومعرفات المراحل لا تُعدل دون ترحيل واختبارات توافق.
- أي دفعة تنظيف تُنفّذ على فرع مراجعة، وتُدمج في `main` فقط بعد موافقة مالك المشروع.

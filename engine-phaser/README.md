# Phaser 4 Adventure Runtime

مشغل مغامرات ثنائي الأبعاد مستقل داخل المشروع. يتضمن اختيار العالمين، الحركة والقفز والتفاعل، ألغاز المناطق، الأختام العنصرية، أدوات البيئة، الأعداء، المهمات الجانبية، الزعيم، وحفظ التقدم محلياً.

## التشغيل
```bash
npm install
npm run dev
```
## البناء والاختبارات
```bash
npm test
npm run build
```
يعتمد على Phaser 4 وVite. يجب تثبيت الاعتماديات أولاً؛ الاختبارات الآلية لا تستبدل تجربة المتصفح أو اختبار اللمس على الأجهزة.

# 2.4.5.1 — network diagnostic
Surgical patch on published 2.4.5, not the unpublished 2.4.7 or 3.0 branch. Six bounded QoS0 self-echo probes per configured broker using independent disposable connections, median/p95 and successive RTT difference; does not measure phone-to-TV or throughput. No broker changes, no persistence, no real game traffic. Synthetic deterministic test: 30ms, 120ms, one lost probe and unavailable broker, cleanup. Physical TV and Saudi network not measured. No pressure tests.

# ضبط دماغك — الإصدار V21 (الحزمة الموحدة ٢)

نسخة عمل جديدة بنيت على «حزمة الكتابة والفن الموحدة ٢». الإصدارات السابقة باقية كما هي للرجوع:
التطبيق القديم في جذر المستودع، وV20 في `v20/`، والفرع `main` في GitHub دون تغيير.

## التشغيل السريع (نسخة مبنية)

```bash
cd v21/dist
python3 -m http.server 8080
```
ثم افتح `http://localhost:8080`. لا تفتح `index.html` بالنقر المزدوج؛ الوحدات والعمل دون اتصال يحتاجان خادمًا (HTTP أو HTTPS).

للهاتف: افتح العنوان من الجوال على الشبكة نفسها (`http://عنوان-الكمبيوتر:8080`) أو ارفع محتوى `dist/` على أي استضافة ثابتة HTTPS، ثم «إضافة إلى الشاشة الرئيسية».

## التطوير والبناء

```bash
cd v21
npm install
npm run dev        # خادم تطوير
npm run build      # بناء dist/ + offline-manifest.json
npm test           # فحص البيانات والمحقق وطبقة الحفظ (Node)
npx vite preview --port 4173 &  &&  python3 tests/e2e.py   # اختبار المتصفح الكامل (Playwright + Chrome)
```

## البنية

- `src/core/validators.js` مدققات القيود المشتركة (ترتيب، توزيع، ذاكرة، مسارات، مرايا، مصابيح، أرقام، إحداثيات، شبكات موزونة، حمولة، توزيع كميات، تحديد مجموعات، قرار قصصي، رسم حر).
- `src/core/widgets.js` واجهات اللعب الحية لكل نوع.
- `src/core/runner.js` شاشة اللغز المشتركة: المشهد، الحوار، الهدف، التراجع، التحقق، التلميحات، كشف الحل بالمساعدة، الحفظ والمسودات.
- `src/core/store.js` الحفظ والترحيل والنسخ الاحتياطي والاستعادة.
- `src/sections/` الأقسام الأربعة وصفحة «رحلتي».
- `public/data/<القسم>/` بيانات كل قسم كما وردت في الحزمة دون خلط.
- `public/assets/` الرسوم الجديدة محوّلة إلى WebP، والرسوم المتجهية.
- `public/sw.js` عامل الخدمة للعمل دون اتصال.
